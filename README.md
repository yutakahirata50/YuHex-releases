# YuHex Free Edition

A free portable hex editor for Windows 11 on Intel/AMD 64-bit PCs.
View, search, and edit binary files with text decoding, a data inspector,
Struct View, and a multilingual interface.

**[Download the latest release](https://github.com/yutakahirata50/YuHex-releases/releases/latest)**

Open Assets and download `YuHex-…-win-x64.zip`.
